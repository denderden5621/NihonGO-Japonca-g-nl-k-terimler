# 🌸 NihongoTR - Kendi Gemini API Anahtarınla Çalışan Tek Dosya (Standalone HTML)

Bu klasördeki **`index.html`** dosyası, herhangi bir Node.js sunucusuna, kuruluma veya ek kütüphane indirmesine ihtiyaç duymadan **tek başına çift tıklanarak doğrudan tarayıcıda çalışan bağımsız sürümdür.**

---

## ✨ Özellikler

1. **%100 Bağımsız & Taşınabilir:** 
   * Tek bir `.html` dosyasıdır.
   * USB belleğe atıp yanınızda taşıyabilir, telefonunuza aktarabilir veya e-posta ile gönderebilirsiniz.
   
2. **Çevrimdışı Çalışma (Offline-First):**
   * Tüm Japonca seyahat kategorileri, Türkçe okunuşlar, kültürel ipuçları, bilgi kartları ve mini testler internet olmadan da tarayıcının yerleşik ses motoruyla çalışır.

3. **İstemci Tarafı Gemini AI Entegrasyonu:**
   * AI Telaffuz Değerlendirmesi ve ses analizi için kendi Google Gemini API anahtarınızı sağ üstteki **"API Anahtarı"** butonundan girebilirsiniz.
   * API anahtarınız sunucuya gitmez; tamamen kendi tarayıcınızın `localStorage` hafızasında güvenle saklanır.

---

## 🔑 Ücretsiz Gemini API Anahtarı Nasıl Alınır?

1. [Google AI Studio (aistudio.google.com/app/apikey)](https://aistudio.google.com/app/apikey) adresine gidin.
2. Google hesabınızla giriş yapın ve **"Create API Key"** butonuna tıklayın.
3. Aldığınız anahtarı kopyalayıp `index.html` sayfasındaki **"API Anahtarı"** kutucuğuna yapıştırın ve **"Kaydet"**e basın.
4. Artık AI Telaffuz Koçu ve sesli değerlendirmeler kendi kotanızla sınırsız şekilde çalışacaktır!
